# 被动监听使用独立可选驱动组件

便携主程序只访问自己拥有的标准 Windows 串口连接，并为监视源保留功能接口。捕获其他程序已打开串口的读写、打开关闭和控制事件使用 KMDF 串口设备栈筛选驱动，只附加到用户明确选择的设备，并由独立用户态桥接进程转发事件。驱动开发依赖 WDK、INF/CAT、测试签名环境以及 HVCI 和 Secure Boot 验证；正式发布优先完成 HLK 测试并通过 Windows Hardware Compatibility Program 签名，attestation 只用于 Microsoft 当前允许的测试场景。驱动安装、升级和卸载均需单独授权。缺少正式签名资源时交付源码、自动测试、测试签名包和发布说明，主应用、便携版和安装版的完成状态不受影响。
