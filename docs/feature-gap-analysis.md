# 功能边界与后续增强

本文档记录当前版本已经接通的能力，以及从日常串口调试角度仍值得增强的部分。当前功能以 `README.md` 为使用说明，代码和实际运行结果优先于本文件中的文字。

## 当前调用链

```text
WinUI / CLI
  → Windows 命名管道 + StreamJsonRpc
  → SerialWorkbench.Host
  → SerialConnectionManager
  → System.IO.Ports.SerialPort
  → EventJournal + SessionStore
```

Host 持有串口句柄、写入租约、原始事件和 SQLite 会话。WinUI 与 CLI 共用 RPC；协议结果、波形和文本都是原始字节的派生视图。

## 已接通功能

- Windows 串口枚举，包含端口描述、VID、PID 和设备实例标识。
- 波特率、数据位、校验、停止位、流控、DTR、RTS 和编码设置。
- 最近使用的串口偏好和命名串口连接配置。
- 在线切换 DTR/RTS、清空 RX/TX 缓冲和发送 BREAK。
- 文本、HEX、行尾和校验追加发送。
- 定时循环发送、交互式终端和输入历史。
- 文本或 HEX 报文监视、时间戳、计数、复制和暂停显示，支持实时方向和来源筛选。
- CSV 文本和固定长度二进制波形。
- Modbus RTU 01、02、03、04、05、06、0F、10、17 请求—响应事务。
- TX 回显、无关 RX、合法响应、CRC 错误、异常码和超时区分。
- Modbus RTU 协议帧查看器。
- 固定、递增、随机模式回环检测，支持停止和会话统计。
- 多步骤自动化发送序列，支持延时、重复、保存、运行和取消。
- XMODEM-CRC 文件发送和接收，支持双 CH340 端到端传输、分块缓存和长度元数据。
- 连接配置保存 `DeviceInstanceId`，当前 WinUI 连接按设备身份自动重连。
- WinUI 连接管理页支持同时打开、切换和关闭多条连接，并保留各自事件历史。
- 连接管理页显示 DTR、RTS、CTS、DSR 和 DCD 状态，RI 在当前串口 API 下显示为未知。
- 连接管理页显示 Host 最新事件序号和持久化队列数量。
- 连接管理页显示每条连接的观察者队列丢弃块数。
- CLI 会话导出支持按序号分页写出 JSONL。
- RS-485 半双工发送支持 RTS 方向控制和发送前后延时。
- CLI 支持从 JSON 文件加载通用协议模板并解析字段、帧长和校验。
- 自动化序列支持按 HEX 响应等待、响应超时和重试。
- WinUI 和 CLI 支持按地址范围扫描 Modbus RTU 从站。
- WinUI 和 CLI 支持按固定间隔轮询 Modbus 位或寄存器。
- SQLite 会话、空会话、事件原始字节、CSV 导出、会话筛选、回放和回环历史。
- 会话事件按序号分页读取，支持连接、方向、来源和 HEX 片段筛选，WinUI 可继续加载后续事件，并可用于 CSV、JSONL 导出。
- CLI CSV、JSONL、TXT、HEX 和原始二进制导出按分页流式写入，不需要把整个会话载入内存。
- 连接管理页显示连接打开以来的平均 RX/TX 字节速率。
- CLI 端口、Host、工作区、发送、监视、回环、Modbus、会话和 XMODEM 命令。
- self-contained `win-x64` 便携发布。

## 仍可增强的功能

### 1. 高速接收与观察者隔离

当前串口读取已经不再等待观察者通道写入，满载观察者使用丢弃旧块策略。后续可以继续增加：

- 持久化队列写入速率显示。
- 最早可用事件序号和丢失区间提示。
- 长时间高速接收压力测试。

### 2. 设备拔出和恢复

仍可增加：

- 设备拔出时的专用连接状态事件。
- 可配置的自动重连间隔和次数。
- 多连接独立恢复、连接列表状态显示和统一时间线。
- 重连后的会话分段和状态提示。
- 串口线路状态事件记录和状态变化通知。

### 3. 串口控制

现有页面已经支持 DTR、RTS、BREAK 和清空 RX/TX 缓冲。后续还可以增加：

- 清除串口错误状态。
- RS-485 方向状态事件记录和硬件收发切换诊断。

### 4. 报文搜索和筛选

实时工作台和 CLI 已支持全部、RX、TX、文本、HEX 和来源筛选，复制操作使用当前筛选结果。后续还可以增加：

- 按长度和时间范围筛选。
- 匹配高亮、上一条、下一条和未读数量。
- 当前筛选结果导出。

### 5. 发送队列和序列条件

现有自动化序列支持固定发送、响应等待、超时和重试，发送历史已经持久化。后续可以增加：

- 条件等待和字段级响应匹配。
- 失败分支。
- 启用/禁用步骤。
- 队列循环。
- 运行日志和每一步结果。
- 发送历史的编码、行尾、校验和使用次数记录。

### 6. Modbus 扩展

当前页面和 CLI 已统一支持 01、02、03、04、05、06、0F、10、17，并可扫描 Modbus RTU 从站。后续可以增加：

- 广播地址。
- 寄存器有符号、位字段、32/64 位组合和浮点解释。
- 大小端选择。
- 超时率、CRC 错误率和按从站统计。

### 7. 会话管理

当前会话已按连接打开和关闭完成生命周期。后续可以增加：

- 会话名称、备注和标签。
- 会话损坏隔离和 SQLite 完整性检查。
- WAL 恢复提示和备份恢复。
- JSON 文件导出。
- 只回放 TX、倍率调整和固定间隔回放。

### 8. 协议模板

CLI 已支持从 JSON 文件加载通用协议模板并解析基础字段。后续可以增加：

- 帧头、帧尾和固定长度。
- 长度字段和字段偏移。
- 整数、浮点、枚举和位字段。
- 大小端和校验范围。
- 请求—响应关联。
- 解析失败位置和字段级错误。

### 9. 波形测量

当前波形支持 CSV 文本和固定长度二进制帧。后续可以增加：

- X 轴时间和采样率。
- Y 轴范围和自动缩放。
- 通道名称、单位、缩放和平移。
- 触发条件。
- 峰值、均值、最小值和最大值。
- PNG、SVG、CSV 导出。
- 丢帧统计和采样窗口。

### 10. 多连接

Host 和 WinUI 连接管理页已经支持同时维护多条连接。后续可以继续增加：

- 多连接独立恢复。
- 统一时间线。
- `DUT`、`DEBUG`、`CONTROLLER`、`LOOPBACK` 逻辑角色。
- 按设备身份绑定配置和任务。

## 验证边界

- COM15 已验证端口枚举、HEX/文本发送、回环、Modbus 回显识别、会话和 CSV。
- COM18 与 COM19 已验证 TX↔RX 交叉连接、裸字节双向通信和 XMODEM-CRC 双端传输。
- XMODEM 当前自有发送端使用长度元数据恢复末尾 `0x1A`；面对不支持该元数据的标准外部 XMODEM 接收端时，仍按传统填充语义运行。
- WinUI 页面已通过 Release 构建和 XAML 编译；桌面按钮的人工视觉验收需要在本机启动应用后进行。
