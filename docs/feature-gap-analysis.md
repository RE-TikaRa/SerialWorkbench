# 功能边界与后续增强

本文档记录当前版本已经接通的能力，以及从日常串口调试角度仍值得增强的部分。当前功能以 `README.md` 为使用说明，代码和实际运行结果优先于本文件中的文字。

## 当前调用链

```text
WinUI / TUI / CLI / Agent
  → Windows 命名管道 + StreamJsonRpc
  → SerialWorkbench.Host
  → SerialConnectionManager
  → System.IO.Ports.SerialPort
  → EventJournal + SessionStore
```

Host 持有串口句柄、写入租约、原始事件和 SQLite 会话。WinUI、TUI 与 CLI 共用 RPC；协议结果、波形和文本都是原始字节的派生视图。

## 已接通功能

- Windows 串口枚举，包含端口描述、VID、PID 和设备实例标识。
- 波特率、数据位、校验、停止位、流控、DTR、RTS 和编码设置。
- 最近使用的串口偏好，以及由 Host 保存并共享的命名连接配置、工作区和发送历史。
- 在线切换 DTR/RTS、清空 RX/TX 缓冲和发送 BREAK。
- 文本、HEX、行尾和校验追加发送。
- HEX 输入严格按两个数字组成一个字节；奇数位或无效字符返回中文输入提示，并保留参数错误退出码。
- 定时循环发送、交互式终端和输入历史。
- 文本或 HEX 报文监视、时间戳、计数、复制和暂停显示，支持实时方向和来源筛选。
- 实时工作台、终端和会话回放文本跨读取块连续显示，按 CR、LF、CRLF 分行，未结束的文本行实时更新。
- HEX 接收数据按可配置空闲间隔合并显示，默认 10 ms；TX 保留发送边界，设为 0 时显示原始读取块。
- 工作台和终端报文支持单条、多条与范围选择、右键复制所选内容和 Ctrl+C，选中时停止自动滚动。
- 所选报文可复制为当前显示、文本、空格分隔 HEX、连续 HEX 或包含时间、方向和来源的日志。
- CSV 文本和固定长度二进制波形。
- Modbus RTU 01、02、03、04、05、06、0F、10、17 请求—响应事务。
- TX 回显、无关 RX、合法响应、CRC 错误、异常码和超时区分。
- Modbus RTU 协议帧查看器。
- 固定、递增、随机模式回环检测，支持停止和会话统计。
- 多步骤自动化发送序列，支持延时、重复、保存、运行和取消。
- XMODEM-CRC 文件发送和接收，支持双 CH340 端到端传输、分块缓存和长度元数据。
- Host 按 `DeviceInstanceId` 自动恢复多条连接，保留共享连接标识；连接状态事件和会话分段区分断线前后的原始数据，周期读取等待恢复。
- WinUI 连接管理页支持同时打开、切换和关闭多条连接，并保留各自事件历史。
- 连接管理页显示 DTR、RTS、CTS、DSR 和 DCD 状态，RI 在当前串口 API 下显示为未知。
- 连接管理页显示 Host 最新事件序号和持久化队列数量。
- 连接管理页显示每条连接的观察者队列丢弃块数。
- CLI 会话导出支持按序号分页写出 JSONL。
- RS-485 半双工发送支持 RTS 方向控制和发送前后延时。
- CLI 支持从 JSON 文件加载通用协议模板并解析字段、帧长和校验。
- 自动化序列支持按 HEX 响应等待、响应超时和重试。
- WinUI 和 CLI 支持按地址范围扫描 Modbus RTU 从站。
- WinUI 和 CLI 支持按固定间隔轮询 Modbus 位或寄存器。
- SQLite 会话、空会话、事件原始字节、CSV 导出、会话筛选、回放和回环历史。
- 会话事件按序号分页读取，支持连接、方向、来源和 HEX 片段筛选，WinUI 可继续加载后续事件，并可用于 CSV、JSONL 导出。
- CLI CSV、JSONL、TXT、HEX 和原始二进制导出按分页流式写入，不需要把整个会话载入内存。
- 连接管理页显示连接打开以来的平均 RX/TX 字节速率。
- Host 状态显示会话事件实际写入速率。
- CLI 端口、Host、工作区、发送、监视、回环、Modbus、会话和 XMODEM 命令。
- CLI 持久连接管理，以及通过 `--connection` 使用现有共享连接；桌面退出保留连接，Host 在连接或写入任务存在时保持运行。
- Host 任务标识、进度、明确取消、结果持久化和请求身份去重；客户端意外断开保留任务，Host 重启标记中断且不重放设备操作。
- CLI 设备命令提供后台执行与持久请求标识，端口请求由 Host 去重并保留连接，后台 XMODEM 接收由 Host 保存文件。
- 实时事件提供流标识、最早和最新序号、过滤后的连续游标及缺失区间；CLI 监视通过长轮询获取数据。
- CLI 使用 System.CommandLine 处理带类型的参数、Help、补全建议和 Response File，使用 Spectre.Console 呈现文本结果，并提供自动化序列入口。
- Agent 与 CLI 共享 Schema v2，提供离线能力发现、命令 Schema 和帮助；结构化错误写入 stdout，JSONL 保持逐条单行并输出最终结果。
- CLI 管理共享连接配置，支持查看、保存、修改、重命名、删除与按配置打开连接；在线 DTR/RTS、缓冲清理和 BREAK 使用同一套 Host RPC。
- CLI 支持发送校验追加、Host 循环发送、分页进度读取和等待已有任务完成，退出等待不取消其他客户端的任务。
- CLI `kill` 关闭当前应用目录的共享连接、Host 和客户端进程，报告退出结果后结束自身；支持 JSON/JSONL 与关闭时限。
- Terminal.Gui 终端工作台提供连接、报文、发送、历史、过滤、设置、暂停、范围选择和复制，复用 WinUI 的文本与 HEX 聚合实现。
- TUI 与 CLI 提供独立入口 `SW_TUI.exe` 和 `SW_CLI.exe`；CLI 无参数显示帮助，Agent 使用相同命令契约。
- TUI 常用工作区支持 Alt+1 至 Alt+5 导航，高级操作通过 F9 的“设备操作”和“数据分析”分组进入独立窗口。
- TUI 工作台集中呈现连接、报文、收发状态与单行发送，F4 连接管理与设置对话框提供串口、显示、筛选和发送选项。
- TUI 支持 Modbus 事务、扫描、轮询、XMODEM 收发、自动化序列、回环，以及 Host 任务进度、取消和结果查询。
- TUI 设置流控、设备角色、DTR/RTS、RS-485 方向延时和自动重连，使用 Host 共享配置及发送历史。
- TUI 提供会话分页、连接／方向／来源／HEX 筛选、五种格式导出、倍率回放和暂停控制，以及通用模板、Modbus 帧分析和库控件波形。
- TUI 独立发送格式、行尾、校验追加与 Host 循环任务；序列步骤编辑、排序、加载保存和运行。
- TUI 报文右键复制、完整详情、来源筛选，连接详情与重连、缓冲清理和 BREAK，Modbus 实时结果与波形导出。
- TUI 使用 Terminal.Gui Scheme 区分焦点、选择、RX/TX、次要信息和操作结果；支持浅色终端、`NO_COLOR`、延迟 ASCII 加载指示、成功提示和错误保留。
- self-contained `win-x64` 便携发布。
- 构建生成 `SW.exe`、`SW_TUI.exe`、`SW_CLI.exe` 和 `SW_HOST.exe`，合并发布保留 `SW.pri`、XBF 与运行时资源。

## 仍可增强的功能

### 1. 高速接收与观察者隔离

当前串口读取已经不再等待观察者通道写入，满载观察者使用丢弃旧块策略。后续可以继续增加：

- 长时间高速接收压力测试。
- 持久化队列深度历史。

### 2. 设备拔出和恢复

仍可增加：

- 可配置的自动重连间隔和次数。
- 多连接统一时间线。
- 串口线路状态事件记录和状态变化通知。

### 3. 串口控制

现有页面已经支持 DTR、RTS、BREAK 和清空 RX/TX 缓冲。后续还可以增加：

- 清除串口错误状态。
- RS-485 方向状态事件记录和硬件收发切换诊断。

### 4. 报文搜索和筛选

实时工作台和 CLI 已支持全部、RX、TX、文本、HEX 和来源筛选，复制操作使用当前筛选结果。后续还可以增加：

- 按长度和时间范围筛选。
- 匹配高亮、上一条、下一条和未读数量。
- 当前筛选结果导出。

### 5. 发送队列和序列条件

现有自动化序列支持固定发送、响应等待、超时和重试，发送历史已经持久化。后续可以增加：

- 条件等待和字段级响应匹配。
- 失败分支。
- 启用/禁用步骤。
- 队列循环。
- 运行日志和每一步结果。
- 发送历史的编码、行尾、校验和使用次数记录。

### 6. Modbus 扩展

当前页面和 CLI 已统一支持 01、02、03、04、05、06、0F、10、17，并可扫描 Modbus RTU 从站。后续可以增加：

- 广播地址。
- 寄存器有符号、位字段、32/64 位组合和浮点解释。
- 大小端选择。
- 超时率、CRC 错误率和按从站统计。

### 7. 会话管理

当前会话已按连接打开和关闭完成生命周期。后续可以增加：

- 会话名称、备注和标签。
- 会话损坏隔离和 SQLite 完整性检查。
- WAL 恢复提示和备份恢复。
- JSON 文件导出。
- 固定间隔回放。

### 8. 协议模板

CLI 与 TUI 已支持从 JSON 文件加载通用协议模板，检查帧头、固定长度或长度字段、字段偏移、数值与 HEX、大小端和校验范围。后续可以增加：

- 帧尾。
- 枚举和位字段。
- 请求—响应关联。
- 解析失败位置和字段级错误。

### 9. 波形测量

当前波形支持 CSV 文本和固定长度二进制帧。后续可以增加：

- X 轴时间和采样率。
- 通道名称和单位。
- 触发条件。
- 峰值、均值、最小值和最大值。
- PNG、SVG 导出。
- 丢帧统计和采样窗口。

### 10. 多连接

Host 和 WinUI 连接管理页已经支持同时维护多条连接。后续可以继续增加：

- 统一时间线。
- 按设备身份绑定配置和任务。

### 11. CLI 业务覆盖

- 会话事件分页筛选查询。
- 波形数据处理与导出命令。

## 验证边界

- 2026-10-07 完整发布对应代码基线 `197fda7`：Release 构建零警告、零错误；212 项测试中 205 项通过、7 项硬件测试跳过。
- 四个发布入口的版本信息一致。发布版验证 CLI/TUI 帮助、离线 Agent 能力与 Schema、kill 的 JSON/JSONL、Host 正常关闭和调用进程退出。
- CH340 COM20 已验证连接打开、kill 关闭连接与 Host、调用进程退出及端口重新打开，未发送数据；端口号只代表该次验证。
- 发布版 `protocol inspect --hex 0` 已验证返回 Schema v2 参数错误，提示每两个十六进制数字组成一个字节；四个入口版本一致，`data` 保留。
- COM15 已验证端口枚举、HEX/文本发送、回环、Modbus 回显识别、会话和 CSV。
- COM18 与 COM19 已验证 TX↔RX 交叉连接、裸字节双向通信和 XMODEM-CRC 双端传输。
- XMODEM 当前自有发送端使用长度元数据恢复末尾 `0x1A`；面对不支持该元数据的标准外部 XMODEM 接收端时，仍按传统填充语义运行。
- WinUI 页面已通过 Release 构建和 XAML 编译；桌面按钮的人工视觉验收需要在本机启动应用后进行。
