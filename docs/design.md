# 产品模型

## 连接

连接由串口参数和设备标识组成，连接资料保存通信参数、设备角色和匹配信息。发送、监视、回环检测和会话记录共享连接状态。

每条连接通过写入租约协调发送操作。发送操作和回环检测持有写入租约，监视和会话记录读取同一数据流。事件按连接、方向、来源和原始字节记录。

## 会话

首次连接时创建活动会话。会话保存原始字节、连接事件、TX/RX 方向、UTC 时间、单调时间、递增序号和查询索引。每个会话使用独立的 `.swbsession` SQLite 文件，结束时完成 WAL checkpoint。会话页可以将完整原始事件导出为 CSV 文件，也可以在不访问串口的情况下按原始时间间隔回放到工作台事件流。

解析结果引用会话中的原始字节，并保存协议模板和解析版本。新的解析版本可以基于同一份原始数据生成，历史结果保留原有版本语义。

## 工作区

应用根目录保存界面设置、日志、全局会话和命名串口连接配置。工作区保存会话。工作区切换通过 Host 完成，客户端根据返回的路径和状态更新界面。

CLI 结构化输出使用带 `schemaVersion` 的 JSON 文档，契约位于 `schemas/`。

## 协议

Modbus RTU 编解码请求和响应，并提供 CRC 校验。会话保存原始数据，协议分析可以在其上建立帧和字段视图。

## 界面

WinUI 页面使用 Windows App SDK 原生控件和共享样式。NavigationView 负责页面选择，页面主体使用 Frame 缓存和导航过渡。SelectorBar 切换报文与波形，SettingsCard 呈现设置项，VisualState 根据内容宽度调整布局。

ScottPlot.WinUI 承载波形图。报文、波形、Modbus、回环、终端、设置和会话页面共享连接与会话数据。终端页面复用工作台连接和事件流，不创建独立串口通道。

## CLI

CLI 提供端口枚举、连接、发送、监视、回环、工作区和会话操作。终端输出使用适合阅读的文本格式，结构化结果使用 JSON 或 JSON Lines；字段契约位于 `schemas/`。
