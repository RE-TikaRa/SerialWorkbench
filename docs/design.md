# 产品模型

## 连接

连接由串口参数和设备标识组成，连接资料保存通信参数、设备角色和匹配信息。发送、监视、回环检测、自动化序列、XMODEM 文件传输和会话记录共享连接状态。

每条连接通过写入租约协调发送操作。发送操作和回环检测持有写入租约，监视和会话记录读取同一数据流。事件按连接、方向、来源和原始字节记录。

## 会话

首次连接时创建活动会话。会话保存原始字节、连接事件、TX/RX 方向、UTC 时间、单调时间、递增序号和查询索引。回环检测结果保存于同一会话的独立统计表，不伪装成串口报文事件。每个会话使用独立的 `.swbsession` SQLite 文件，结束时完成 WAL checkpoint。会话页可以将完整原始事件导出为 CSV 文件，也可以在不访问串口的情况下按原始时间间隔回放到工作台事件流。

协议分析以会话或输入中的原始字节生成帧与字段视图。通用协议模板使用 JSON 描述帧头、长度、字段偏移、数值类型、大小端与校验范围。

## 工作区

应用根目录保存界面设置、日志、全局会话和命名串口连接配置。工作区保存会话。工作区切换通过 Host 完成，客户端根据返回的路径和状态更新界面。

CLI 结构化输出使用带 `schemaVersion` 的 JSON 文档，契约位于 `schemas/`。

## 协议

Modbus RTU 编解码请求和响应，并提供 CRC 校验。事务处理区分 TX 回显、无关接收数据、合法响应、CRC 错误、超时和异常码。会话保存原始数据，协议分析可以在其上建立帧和字段视图。

## 界面

GUI 提供完整的人机交互，承载复杂配置、设备管理、波形与数据可视化。TUI 面向终端中的人工操作，以连接、收发、日志和常用配置为主要流程。CLI 承担程序控制，Agent 只通过 `SW_CLI.exe --agent` 使用机器接口。核心设备操作、数据处理、配置、采集与导出均以命令接口覆盖为目标。GUI、TUI 和 CLI 共享 Host 和 RPC，Agent 消费 CLI 的稳定输出。

TUI 工作台集中显示连接、报文、发送与收发状态。常用工作区通过编号导航，高级协议、传输、自动化和波形操作由工具入口打开。参数按用途组织到设置对话框，连接和报文数据保留在 Host 与共享解析实现中。

TUI 使用 Terminal.Gui 的语义样式区分正文、次要信息、焦点、选择与操作结果。配色随终端背景检测切换，`NO_COLOR` 使用无色样式；页面切换和对话框返回保留焦点与编辑状态。加载指示延迟显示，成功提示短暂强调，错误保留；任务进度以 Host 的实际计数呈现，设置页可关闭轻量动效。

HEX 输入以两个十六进制数字表示一个字节，允许空格、逗号、短横线、冒号和 `0x` 前缀作为分隔。奇数位输入不会自动补位，客户端返回中文提示和 `0A` 示例，避免改变设备数据含义。

WinUI 页面使用 Windows App SDK 原生控件和共享样式。NavigationView 负责页面选择，页面主体使用 Frame 缓存和导航过渡。SelectorBar 切换报文与波形，SettingsCard 呈现设置项，VisualState 根据内容宽度调整布局。

ScottPlot.WinUI 承载波形图。报文、波形、Modbus、协议帧、回环、终端、设置和会话页面共享连接与会话数据。终端页面复用工作台连接和事件流，不创建独立串口通道。

## CLI

CLI 提供端口枚举、连接、发送、监视、回环、Modbus 事务、工作区和会话操作。终端输出使用适合阅读的文本格式，结构化结果使用 JSON 或 JSON Lines；字段契约位于 `schemas/`。

System.CommandLine 定义命令树和带类型的参数，处理 Help、补全建议与 Response File。Spectre.Console 呈现一次性文本结果。离线协议检查和命令帮助独立于 Host 生命周期。

`SW_CLI.exe` 无参数显示帮助，`SW_TUI.exe` 无参数启动终端工作台；GUI 入口为 `SW.exe`，共享服务为 `SW_HOST.exe`。各客户端使用同目录的 Host，也可通过 CLI/TUI 的 `--app-root` 指定应用目录。

`kill` 结束目标应用目录的客户端、共享连接与 Host，结果输出后结束调用进程。连接关闭取消对应任务并完成会话；Host 不可响应或超过关闭时限时，结果记录强制退出及可能的关闭错误。

Agent 和 CLI 的 JSON 输出共享 Schema v2，Agent 通过 `SW_CLI.exe --agent` 获取固定信封和命令特定的结果结构。所有契约记录写入 stdout，诊断写入 stderr。JSONL 一行一条记录，流结束时输出最终结果。能力描述、参数和结果 Schema 根据命令树及实际类型生成。
